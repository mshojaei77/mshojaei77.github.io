### File imports and post deletion

Use Import to create a local article from a UTF-8 `.md`, `.markdown` or `.html` file (950 KB including generated metadata). Recognized front matter suggests title, description, language and slug; review them in the dialog. HTML fragments are preserved; full HTML documents import only their body, not head styles or scripts outside it. Use Import file within an existing article to replace its body with the same format while retaining its original path and front matter. No automatic cross-format conversion. Only import trusted authored content; review HTML, links and Liquid before publishing.

Delete post asks for confirmation, then removes the original source and creates a localized noindex removal page at the same permalink in one atomic commit. Retry checks for an already committed deletion; a known failed deletion may be cancelled. The post disappears from the archive and feed after merge, its old URL still works, and Git history and media remain. Deleted permalinks are reserved. Local-only drafts can be removed with Discard local draft. Legacy pending PRs must be resolved first. Page deletion is not supported.

### IndexNow

The public root file `<key>.txt` is the IndexNow ownership proof; its value is intentionally public by protocol and is not an account credential. `_data/discovery.json` is its source of truth, and CI checks that the generated root file matches exactly and stays out of the editorial sitemap. After a successful GitHub Pages deployment, `.github/workflows/indexnow.yml` compares the deployed commit to the preceding successful Pages deployment, detects changed article permalinks, validates the current production sitemap/canonical routes, then sends only changed article URLs and their language archive. Retired canonical URLs are sent only as removal notifications when a retirement tombstone is present and absent from the sitemap. The workflow skips superseded runs, seeds rather than bulk-submitting when no prior baseline exists, and records accepted HTTP status in its run log. A 200/202 response means the notification was received; it does not mean an URL was indexed. No content URLs are submitted by ordinary CI or dashboard views.

The public robots policy uses `User-agent: *`, disallows `/admin/` and `/.git/`, and permits the public site to all other crawlers, including search, AI search, and training crawlers.
