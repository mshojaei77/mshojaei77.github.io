{% if page.lang == 'fa' %}تعریف معیارها و فرض‌ها{% else %}Metric definitions and assumptions{% endif %}
  • Precision@K = relevant retrieved / K; unfilled ranks count as non-relevant.
  • Recall@K = relevant retrieved / all positively judged documents.
  • MRR averages reciprocal rank across every query; queries without relevant judgments contribute zero.
  • DCG@K = Σ (2^grade − 1) / log₂(rank + 1); NDCG@K divides by the ideal DCG from supplied positive grades.
  • MAP averages precision at each relevant rank, divided by the number of positively judged documents; no-positive queries contribute zero.
  • {% if page.lang == 'fa' %}رتبه‌بندی‌های تکراری فقط در اولین جایگاه نگه داشته می‌شوند. سندهای بدون برچسب، relevance برابر صفر دارند؛ بنابراین تکمیل judgmentها برای تفسیر معتبر مهم است. این معیارها کیفیت کل سامانهٔ RAG را اندازه نمی‌گیرند.{% else %}Duplicate ranked IDs keep their first occurrence. Unjudged documents receive relevance zero, so complete judgments matter for interpretation. These metrics do not measure complete RAG quality.{% endif %}
