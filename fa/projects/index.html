متن‌باز

پروژه‌ها

بعضی از چیزهایی که می‌سازم به یک ابزار قابل‌استفاده تبدیل می‌شوند و بعضی در حد آزمایش می‌مانند. اینجا چند نمونه از کارهای عمومی‌ام را گذاشته‌ام؛ برای وضعیت فعلی، نحوهٔ اجرا و محدودیت‌های هر پروژه، README مخزن را ببینید.

پروژه‌های منتخب

متن‌باز · MCP

ReActMCP

با MCP، دستیار هوش مصنوعی می‌تواند از جست‌وجوی وب Exa به‌عنوان ابزار استفاده کند. این مخزن سرور و کلاینت آن را دارد.

متن‌باز · Python

pytsetmc-api

یک کلاینت Python برای داده‌های بورس تهران، با Type Hint، اعتبارسنجی، Retry و تست؛ تا لازم نباشد هر بار از صفر شروع کنیم.

مدل و داده

Hugging Face

مدل‌ها، دیتاست‌ها، آداپترها و کارهای ارزیابی، از جمله آزمایش‌های مرتبط با پردازش زبان فارسی.

کد و آزمایش

مخازن GitHub

کدها، ابزارها و آزمایش‌هایم؛ از پروژه‌های جدی‌تر تا ایده‌هایی که هنوز مشغول ور رفتن با آن‌ها هستم.

کارهای حرفه‌ای
