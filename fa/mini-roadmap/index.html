نقشهٔ راه فشرده

اگر هنوز نمی‌دانید از کجای مسیر LLM شروع کنید، لازم نیست از همان اول وارد جزئیات همهٔ مباحث شوید. این نسخهٔ تصویری کمک می‌کند تصویر کلی را ببینید و نقطهٔ شروع مناسب تجربه‌تان را پیدا کنید.

برای پیدا کردن مسیر، نه حفظ کردن فهرست

نقشهٔ تصویری، پیش‌نیازهای برنامه‌نویسی، ریاضی و ML را کنار چهار بخش اصلی می‌گذارد: مبانی، ساخت و آموزش مدل، موضوعات پیشرفته و مهندسی کاربردی.

مثلاً اگر Python و مبانی ML را بلدید و هدفتان ساخت اپلیکیشن است، می‌توانید زودتر سراغ استفاده از مدل، RAG و ارزیابی بروید و مباحث آموزش را بر اساس نیاز تکمیل کنید. اگر هدفتان Model Training است، داده و مبانی معماری اهمیت بیشتری پیدا می‌کنند. این مسیر پیشنهادی است، نه پیش‌نیاز قطعی برای همه.

نسخهٔ کامل

این نوشته معرفی فارسی مطلب و چند نکته برای شروع است، نه ترجمهٔ کامل. برای خواندن جزئیات، به متن اصلی انگلیسی بروید.
