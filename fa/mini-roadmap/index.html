شروع سریع

با سابقهٔ برنامه‌نویسی: در صورت نیاز Python را مرور کنید و از شبکه‌های عصبی در بخش اول شروع کنید.

پیشرفته

با تجربهٔ ML/AI: از بخش دوم یا موضوع موردعلاقه شروع کنید؛ بخش اول مرجع شما باشد.

مهندسی LLM

برای ساخت سریع اپلیکیشن: پیش‌نیاز Python و APIهای پایه؛ مسیر بخش اول تا بخش چهارم؛ خروجی اپلیکیشن‌های LLM در Production.
